# Choose the optional control interface

Type: grilling
Status: open
Blocked by: 06, 07

## Question

Given the chosen Eye Display architecture and remaining time, should the build include on-demand control? If so, which Pocket Controller or Phone Controller approach is easiest and fastest to implement, and what transport, selection layout, brightness adjustment, feedback, and connection behavior will it support?

## Context

- [Define control and event operation](03-define-control-and-event-operation.md) records the agreed behavior and makes controls optional.
- [Choose the Eye Display technology and architecture](06-choose-eye-display-architecture.md) determines the hardware the control must work with.
- [Confirm the build deadline and minimum milestone](07-confirm-build-deadline-and-minimum-milestone.md) determines the time available for extras.
- Prefer direct access to several Expressions. A Pocket Controller should work by feel with gloves and a locked phone; a Phone Controller alone requires phone access.
